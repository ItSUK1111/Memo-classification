# Prism Note - AIによるメモ＆タスク自動分類アプリ

👉 **[実際のアプリを触ってみる](https://memo-classification.vercel.app)**

## 概要 
AI駆動型のタスク・メモ管理アプリケーションです。
頭に浮かんだ雑多な文章をまとめて入力するだけで、生成AI（Gemini API）が内容を解釈し、タスクとメモに自動で分類します。なんとなく書き留めてみたメモがたまりすぎて、読み返して分類するのがめんどくさい...といった場合にもメモをまとめて貼り付ければ分類してくれます。

ベースは自分で作りました(ベースになっているTodoアプリの製作からai apiの導入あたりまで)が、大部分はGoogle Antigravityを使用してコードを生成しました。(仕様は自分で考えています)

## 初期仕様 
* **AI自動分類:** ユーザーの入力テキストをAIが解析し、タスクとメモに自動判定。
* **カテゴリ振り分け:** 「仕事」「家事」「買い物」など、文脈に応じたカテゴリへ自動で割り当て。
* カテゴリはデフォルトで用意されているものに加え、自分で追加することも可能。
* **日付でグループ分け:** 入力した日付ごとにタイムライン形式で表示。

## 改善と追加仕様
開発を進める中で、より使いやすくするためにに以下の改修を行いました。

### 1. AI解析精度の向上
* **複合文を分離:** 「明日会議だから資料を作る」といった入力に対し、AIが「資料を作る（タスク）」と「明日の会議（メモ）」の2つに分解して抽出するようプロンプトを調整。
* **相対日時の処理:** AIへのシステムプロンプトに現在時刻をリアルタイムで入力されるようにし、「明日」「来週」といった相対的な時間表現を正確に解釈できるように改善。

### 2. 直感的なUI/UX（ドラッグ＆ドロップ）
* **カテゴリ間の移動と並び替え:**分類されたアイテムを自由に別カテゴリへ移動・並び替え可能に。
* **空枠の保持機能:** カテゴリ内のアイテムが0件になっても空枠を維持し、もし後からその枠に戻したくなっても戻せるように。

### 3. 情報の関連付け（親子付け機能）
* **タスクへのメモ紐づけ:** 「メモ」を「タスク」の上にドラッグ＆ドロップすることで、タスクの配下に子要素として格納される機能を実装。
* **タグの自動同期:** 紐づけ時、親タスクが持つタグを子メモへ自動的に同期させる仕様を追加。解除時には元の状態へ復元。

### 4. 視認性と操作性向上
* **ピン留めとジャンプアニメーション:** 重要なアイテムを画面上部に固定（最大10件）。クリックすると元のアイテム位置へスクロールし、ハイライト点滅でわかりやすいように。
* **一括手動タグ付け:** 入力時に特定のタグ（例: `#就活`）を付与し、グループ分けしやすくする機能。
* **閉じるUI:** 画面を圧迫していたAIが参考にするカテゴリを開閉式に変更し、画面を広く使えるように。
* **フォールバック処理:** APIキー未設定時やAIエラー時には、正規表現と辞書ベースによるローカル分類へ自動で切り替わるようにした。

### これから改善したいこと
今はVueで表面的に動いているだけで、タスクやメモのデータを保存することができない。今後はデータベースやバックエンドを実装するorクラウドサービスで代用してちゃんとデータが保存されるようにしたい。できればユーザー登録して使う仕組みにしたいと考えています。
